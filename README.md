# 🧠 Mansik Santulan Score
### ML-Based Mental Health Analysis & Prediction

A Machine Learning-based web application that analyzes the relationship between students' social media usage, lifestyle habits, and mental well-being. It uses a trained ML model to predict a mental health score based on factors such as screen time, sleep hours, study hours, physical activity, and stress levels.
